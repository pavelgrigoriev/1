# Учебный проект Git & Bash

## Описание
Небольшой учебный проект для отработки навыков работы с Git и написания bash-скриптов резервного копирования.

## Возможности
- Инициализация локального репозитория и работа с ветками
- Скрипт `backup.sh` для создания архивов с датой в имени
- Проверка существования каталогов перед копированием
- Вывод размера созданного архива в человекочитаемом виде
- Документирование всех шагов в Markdown

## Установка

1. Клонируйте репозиторий:
   `git clone git@github.com:username/git-task.git`
2. Перейдите в каталог проекта:
   `cd git-task`
3. Сделайте скрипт исполняемым:
   `chmod +x backup.sh`
4. Запустите скрипт с указанием источника и назначения:
   `./backup.sh ./source ./backups`

## Параметры скрипта

| Аргумент | Тип | Описание |
|----------|-----|----------|
| `SRC` | каталог | Каталог-источник для архивации |
| `DST` | каталог | Каталог, куда сохраняется архив |
| `DATE` | строка | Дата в формате `YYYY-MM-DD` для имени архива |

## Пример запуска

```bash
./backup.sh ~/test_project ~/backups
# Архив создан: /home/user/backups/backup_2026-11-02.tar.gz
# Размер архива: 101K
```
